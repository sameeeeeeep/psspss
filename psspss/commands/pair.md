---
description: Get a fresh psspss pairing code (QR) for another phone or laptop
allowed-tools: Bash(node:*)
---

Run:

```
node "${CLAUDE_PLUGIN_ROOT}/bin/psspss.mjs" pair
```

Show the user the QR block from the output exactly as printed (in a code block so it renders), plus the 6-character code (ABC-DEF) and that it works for 10 minutes at psspss.dev/pair.
